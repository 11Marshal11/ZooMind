# ZooMind API

REST API для магазина товаров для животных.

## Стек

- Django 5
- Django REST Framework
- PostgreSQL
- Redis
- Celery
- Celery Beat
- Flower
- Docker
- Docker Compose
- JWT
- drf-spectacular (Swagger)

## Возможности

- JWT авторизация
- CRUD питомцев
- CRUD товаров
- CRUD заказов
- Кэширование Redis
- Celery задачи
- Периодические задачи Celery Beat
- Swagger
- Покрытие тестами
- Docker
